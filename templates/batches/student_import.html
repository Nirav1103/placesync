CSV Formatting Schema

Your CSV file columns must match the headers specified below. You can copy the following template header:

Enrollment Number,Student Name,Email,Phone,Department,Semester,Division,SPI,CPI,CGPA,Current Backlogs,Passing Year

Schema Guidelines:

  • Enrollment Number: (Required) Serves as student ID and login username.
  • Student Name: (Required) Full candidate name.
  • Email: (Required) Candidate email address (must be unique).
  • Phone: (Optional) Candidate contact number.
  • Department: (Optional) Code of department.
  • Semester: (Optional) Current active semester (e.g. 1 to 8).
  • Division: (Optional) e.g. A, B, C.
  • SPI / CPI / CGPA: (Optional) Academic grades (Decimals out of 10.00).
  • Current Backlogs: (Optional) Number of active backlogs (Defaults to 0).
  • Passing Year: (Optional) e.g. 2027.
